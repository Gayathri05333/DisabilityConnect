# Images Folder

This mini project uses hosted Unsplash image URLs directly in the HTML/JS/DataSeeder
so the app looks complete out of the box without requiring you to source image files.

If you'd like to use local images instead (recommended for offline demos or a
final submission), drop files with these names into this folder and update the
`src="..."` / `image` values in the corresponding HTML/JS files to point at
`images/<filename>` instead of the Unsplash URL:

- logo.png            -> used in navbar / favicon (optional)
- banner.jpg           -> hero banner background (optional, currently a CSS gradient)
- wheelchair.png        -> accessibility icon
- hospital.png          -> hospital card icon
- emergency.png         -> emergency SOS icon
- location.png          -> location/SOS icon
- accessibility.png     -> general accessibility icon
- park.jpg              -> sample "Park" category place photo
- college.jpg           -> sample "College" category place photo
- mall.jpg              -> sample "Shopping Mall" category place photo

None of these are copyrighted — use your own photos or free stock images
(e.g. Unsplash, Pexels) if you replace the hosted URLs.
